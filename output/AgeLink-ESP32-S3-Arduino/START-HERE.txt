AgeLink ESP32-S3 / Arduino IDE 2

1. Extract this ZIP. Open esp32_firmware_modular/esp32_firmware_modular.ino.
   Keep the folder name, all source files, partitions.csv, and data/ together.
2. Install esp32 by Espressif Systems (Arduino core 3.x).
   Boards Manager URL: https://espressif.github.io/arduino-esp32/package_esp32_index.json
   Select ESP32S3 Dev Module, the USB port, and the board's actual flash size.
   The included partitions.csv requires at least 8 MB of flash.
   In Tools > Partition Scheme select Huge APP (3MB No OTA/1MB SPIFFS).
   This sets the IDE's 3 MiB program size limit. The sketch-local
   partitions.csv supplies the actual flash layout, including the larger
   LittleFS partition for the WAVs.
3. Install U8g2, ArduinoJson, ESP8266Audio, and Firebase ESP32 Client (Mobizt).
4. In age_link_config.h check OLED_IS_SH1106 and OLED_I2C_ADDRESS.
   Defaults: 128x64 SH1106 I2C display at 0x3C, SDA GPIO8, SCL GPIO9.
   For an SSD1306 OLED set OLED_IS_SH1106 to false. Power the OLED from 3V3
   only if the breakout supports 3.3 V. Confirm the address with an I2C scan.
5. Disconnect the UPS output from the DevKit before powering via USB.
   Click Verify, then Upload. Upload LittleFS from this sketch's data/ folder
   using the Arduino IDE 2 LittleFS uploader. Close Serial Monitor first.
   A filesystem upload replaces the saved pairing, schedule, and contacts.
6. Pair with the AgeLink Flutter app, add an emergency contact you can test
   with, and sync a schedule. Check Serial Monitor at 115200 baud.

GPIO: OLED SDA 8 / SCL 9; I2S BCLK 4 / LRC 5 / DIN 6;
Medicine Taken 7 / SOS 10; green/orange/red LEDs 14/12/13;
modem ESP TX 17 -> RXD and ESP RX 16 <- TXD.
The SIM800L power and UART level interface depend on the breakout.

Offline reminders need an already synchronized clock and a cached schedule.
After a cold boot without network time, reminders wait for valid time.
SOS needs a saved contact and cellular service. Offline dose events are
handled locally and are not queued for later upload to Firebase.

OLED Home shows the time, next dose, and Wi-Fi signal bars. The Bluetooth
setup screen shows the pairing name, then prompts for Wi-Fi details.
If the audio already works with this partition table, upload only the
sketch for this update so you keep the existing LittleFS contents.
